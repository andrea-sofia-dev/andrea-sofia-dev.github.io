01 / How I work

Agentic engineering, with a human in charge

I work with Claude Code every day. The agent does the typing; I own the architecture, the rules and the result.

  1. 01

    Set the rules

    Goal, limits and what the agent must never touch, written into the project before any code.

  2. 02

    Build

    The agent reads the code, writes the change and runs the tools: tests, linters, the server's own PHP version.

  3. 03

    Verify

    Before and after every release: backup, syntax check, live pages, browser console, error log.

  4. 04

    Ship small

    One step at a time, with a rollback command ready. If something looks off, it stops and asks.

wp-doctor

CLI · MCP

PageSpeed tells you the server is slow; wp-doctor tells you why, and whether real visitors get the cache: with a consent cookie, with utm_* parameters, on a phone.

  • MCP server: an AI agent runs the checks and proposes fixes for your stack
  • Recognises Cloudflare, Fastly, Varnish, LiteSpeed and the main WordPress cache plugins
  • Zero dependencies · results in the terminal, as JSON or as an HTML report
